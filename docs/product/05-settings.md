# 05. Настройки

Раздел `/settings`: слева вертикальное подменю, справа контент. Все изменения сохраняются сразу (инлайн-редактирование) или кнопкой в форме. Ни одно действие здесь не удаляет факты: архивирование скрывает, но история остаётся.

| Подраздел | Что настраивается |
| --- | --- |
| [Сайты](#sites) | Список тьюбов, привязка к AdSpyglass и Метрике, статус |
| [Бандлы](#bundles) | Группы сайтов, цвет, состав |
| [Закупка](#costs) | Ставки закупки по умолчанию и импорт фактического расхода |
| [Сетки](#networks) | Справочник рекламных сеток, цвета, тип |
| [Интеграции](#integrations) | Токены, статус ингеста, ручной перезапуск, нераспознанные гео |
| [Доступ](#access) | Пароль приложения, MCP-токен |

---

<a id="sites"></a>
## `/settings/sites`

Таблица всех сайтов: Домен · Название · AdSpyglass ID · Счётчик Метрики · Бандлы · Статус · Дата запуска · Последний ингест (оба источника) · действия.

- **Добавление:** пустая строка в конце таблицы, без модалки. Обязателен домен и хотя бы один из двух ID.
- **«Проверить»** у строки: запрашивает оба API за вчера и показывает, пришли ли данные («AdSpyglass: 12 480 загрузок · Метрика: 3 211 уников»). Опечатка в ID видна сразу, а не через сутки пустого графика.
- **Импорт из AdSpyglass:** кнопка «Подтянуть сайты» берёт список `group_by=website` и предлагает добавить отсутствующие домены с уже заполненным ID.
- **Статусы:** `ACTIVE` участвует везде · `PAUSED` не тянется ингестом, история видна · `ARCHIVED` скрыт из списков и итогов.
- **Массовые действия:** выделить строки → добавить в бандл / убрать из бандла / сменить статус.
- **Валидация:** домен уникален и приводится к нижнему регистру без `www.`; ID AdSpyglass уникален.

<a id="bundles"></a>
## `/settings/bundles`

Список: Название · Слаг · Цвет · Сайтов · Выручка за 30 дней.

- Редактирование состава — два списка рядом («В бандле» / «Остальные») с поиском и чекбоксами.
- Рядом с каждым сайтом — все его бандлы: пересечения должны быть на виду.
- Цвет — выбор из категориальной палитры; уже занятые цвета помечены.
- Слаг меняется с предупреждением: старые ссылки перестанут работать.

<a id="costs"></a>
## `/settings/costs`

**Блок «Ставки»** — таблица `CostRate`: Источник · Сайт (или «все») · Гео (или «все») · Модель (CPM / CPC / CPU / FLAT) · Ставка · Действует с · по.

- Новая ставка с той же областью автоматически закрывает предыдущую датой `validTo = validFrom − 1 день`.
- Разрешение конфликтов — от частного к общему: сайт + гео > сайт > гео > глобальная.
- Кнопка «Пересчитать расход» за выбранный период запускает джоб `costs:recalc` и показывает, сколько строк изменится.
- Предупреждение, если у активного сайта с трафиком нет ни одной применимой ставки.

**Блок «Импорт фактического расхода»**

- Загрузка CSV `date, domain, country, source, uniques, cost`. Опционально — подключённый Google Sheet (перенос из adkai).
- Предпросмотр до записи: строк распознано · доменов не найдено · гео не смаплено · итоговая сумма · сколько расчётных строк будет перекрыто.
- Импортированное всегда перекрывает расчётное по ставкам, в `FactCost.origin` пишется `IMPORT`.
- История импортов: файл, дата, строк, сумма, кнопка «Откатить импорт».

**Источники закупки** — небольшой справочник (TubeCrown, TubeTraffic/ixxx, …): слаг, название, валюта всегда USD.

<a id="networks"></a>
## `/settings/networks`

Справочник сеток: Слаг · Название · Тип (MEDIATED / DIRECT / MARKETPLACE) · Цвет · Показывать в легенде.

- Новая сетка из AdSpyglass создаётся ингестом автоматически, с серым цветом «Прочее». Здесь ей назначают цвет.
- Больше шести цветных сеток нельзя: остальные схлопываются в «Прочее» на всех графиках.
- `own_deals` — системная сетка, её нельзя удалить, цвет — зелёный.

<a id="integrations"></a>
## `/settings/integrations`

**Подключения:** AdSpyglass (email + токен), Яндекс Метрика (OAuth-токен), S3 для сырья. Значения хранятся в `.env` на сервере; страница показывает только статус («задан / не задан», последние 4 символа) и кнопку «Проверить соединение». Менять токены через UI в v1 нельзя — это сделано намеренно, чтобы секреты не лежали в базе.

**Ингест:**
- Карточка на каждый джоб: расписание, последний запуск, статус, длительность, строк записано, следующий запуск.
- Лог `IngestRun` за 7 дней: источник · окно · статус · строк · длительность · ошибка (раскрывается) · ссылка на сырой ответ в S3.
- **Ручной перезапуск:** источник, диапазон дат, (опционально) сайт → ставит джоб в очередь и показывает его прогресс.
- **Бэкфилл:** то же, но с предупреждением о числе запросов к API.

**Нераспознанные гео** (`#geo`): сырое название · источник · сколько строк ушло в `XX` · поле выбора ISO-кода с автодополнением. После сопоставления кнопка «Пересчитать» перезаписывает затронутые строки из сырья в S3, без повторного обхода API.

<a id="access"></a>
## `/settings/access`

- Смена пароля приложения: текущий + новый; все сессии, кроме текущей, сбрасываются.
- MCP-токен: показать один раз при создании, перевыпустить, дата последнего использования. URL для коннектора Claude: `https://<домен>/api/mcp`.
