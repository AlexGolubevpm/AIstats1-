# 11. Документация

## Правило

**Каждый PR, который меняет поведение, обновляет документацию в том же PR.** Документация описывает текущее состояние системы, а не планы: если код и документ расходятся, это баг.

## Что где обновлять

| Изменение | Документ |
| --- | --- |
| Новая или изменённая страница, блок, действие | [`product/03-pages.md`](../product/03-pages.md), при необходимости [`02-information-architecture.md`](../product/02-information-architecture.md) |
| Финансы, фикс-дилы | [`product/04-finance-and-deals.md`](../product/04-finance-and-deals.md) |
| Настройки | [`product/05-settings.md`](../product/05-settings.md) |
| Формула, порог, правило алерта | [`product/06-metrics.md`](../product/06-metrics.md) |
| Токен, компонент, паттерн UI | [`design/07-design-system.md`](../design/07-design-system.md) |
| Модель данных, API, джоб, структура кода | [`architecture/08-backend.md`](../architecture/08-backend.md) |
| Инструмент MCP, вьюха | [`architecture/09-mcp.md`](../architecture/09-mcp.md) |
| Деплой, сервер, секреты | [`CICD.md`](../CICD.md) |
| Переменная окружения | `.env.example` + раздел в `08-backend.md` |
| Решение с альтернативами | Новый ADR в [`adr/`](../adr/) |

## ADR

Любое решение, которое отклоняется от спецификации или выбирает между несколькими разумными вариантами, фиксируется в `docs/adr/NNNN-название.md` по шаблону [`0000-template.md`](../adr/0000-template.md): контекст, решение, альтернативы, последствия. ADR не редактируются задним числом — если решение меняется, пишется новый ADR со ссылкой на старый.

## Документация в коде

- Комментарий объясняет **почему**, а не что. Не пересказываем код.
- Модули в `server/domain` и `server/ingest` начинаются с короткого комментария: за что модуль отвечает и какие инварианты держит.
- Публичные функции `lib/metrics.ts` — с JSDoc: формула и единицы измерения.

## Стиль

- Русский язык, короткие предложения, таблицы вместо длинных списков.
- Термины — из [глоссария](../product/01-overview.md#глоссарий).
- Каждый документ начинается с вопроса, на который он отвечает, или с одной строки назначения.
