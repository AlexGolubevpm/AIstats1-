# 0008. Прогноз месяца по среднему темпу; расход без страны раскладывается по загрузкам

- Статус: принято; раздел «Гео» уточнён [ADR 0015](0015-geo-cost-allocation.md) (revshare-расход — по выручке, раскладка во вьюхе, выручка без страны не раскладывается)
- Дата: 2026-10-03

## Контекст

1. Владелец хочет видеть, чем закончится месяц «с текущей динамикой трёх дней», с прорисовкой каждого дня. Данных по сайтам — с 01.10, то есть на момент решения три дня.
2. На странице сайта в гео-разрезе появилась строка «Все страны ZZ» с расходом и ROMI −100%, а у стран расход «—». `ZZ` — код «без страны»: ADOK не отдаёт разрез «источник трафика × страна», и весь расход источников (ADR 0006), флэт-дилы и почасовые итоги без стран лежат в нём. Алерт «Убыточное гео» принимал `ZZ` за страну.

## Решение

**Прогноз.** Темп = среднее по последним N полным дням (N = 3 / 7 / 14, по умолчанию 7; день без данных пропускается). Прогноз месяца = факт + темп × оставшиеся дни (сегодня — оставшийся). Отдельно для выручки и расхода на трафик; опер. расходы известны на весь месяц; маржа после них. По сайтам — по собственному темпу сайта. Без недельной сезонности, тренда и доверительных интервалов.

**Гео.** В таблицах гео деньги `ZZ` раскладываются по реальным странам пропорционально загрузкам (закупленный трафик — это загрузки) методом наибольшего остатка до цента (`spreadNoCountry` в `queries/reports.ts`), строки помечаются как оценка (тултип у «Расход»). Строка «Без страны» остаётся только там, где стран нет вовсе, без ROMI. Факты и вьюхи не меняются: `v_site_geo_daily` по-прежнему хранит `ZZ`; `lossGeo` исключает `ZZ`; `geoMatrix` раскладывает по сайту.

## Альтернативы

- **Сезонность по дням недели / линейный тренд в прогнозе.** На трёх днях данных это шум с видом точности. Вернёмся, когда будет ≥ 8 недель истории (бэкфилл).
- **Раскладывать `ZZ` во вьюхе.** Тогда «оценка» неотличима от факта в MCP и экспорте. Оставили во вьюхе факт, в таблицах — оценку с пометкой.
- **Прятать `ZZ`, расход по странам не показывать.** Тогда страница сайта не отвечает на вопрос «какие гео убыточны», ради которого и существует.
- **Раскладывать по выручке, а не по загрузкам.** Закупка оплачивается за трафик, а не за выручку; раскладка по выручке делала бы все страны одинаково прибыльными.

## Последствия

- ROMI по странам — оценка; по сайту, бандлу и сети — точный. В тултипе колонки это сказано.
- Прогноз первые недели будет заметно гулять день ото дня; предупреждение показывается, пока полных дней меньше N.
- Сохранение дила теперь сразу считает прогноз от даты начала (≤ 92 дней назад) до сегодня — страницы не ждут ночи.
