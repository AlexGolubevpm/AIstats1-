# 0003. Светлая тема по умолчанию

- Статус: принято
- Дата: 2026-09-23

## Контекст

В дизайн-системе тёмная тема была основной. Владелец прислал референс дашборда: светлый фон, белые карточки с мягкой тенью, синий акцент, KPI-карточки с иконкой, спарклайном и дельтой, сайдбар с логотипом и индикатором MCP внизу.

## Решение

- Светлая тема — по умолчанию (`:root`), тёмная — `data-theme="dark"`, переключатель в сайдбаре, выбор хранится в браузере.
- Компоновка и компоненты повторяют референс. Круговую диаграмму выручки по бандлам из референса заменяют столбцы: спецификация запрещает pie-чарты, а сумма бандлов ≠ сети.
- График на сводке — выручка по сеткам (а не по бандлам) с линией расхода: сетки не пересекаются, бандлы — пересекаются.

## Альтернативы

- Оставить тёмную тему основной — расходится с тем, что владелец хочет видеть.
- Donut по бандлам как в референсе — вводит в заблуждение из-за пересечений.

## Последствия

- Токены в `globals.css`: светлые в `:root`, тёмные в `[data-theme=dark]`. [07-design-system](../design/07-design-system.md) обновлён.
