# 0010. Каталог мест пополняется из зон AdSpyglass

- Статус: принято
- Дата: 2026-10-06

## Контекст

Каталог мест (`Placement`) сеялся десятью местами владельца (Tablink 1–3, Underplayer…), а зоны ADOK привязывались к ним только при совпадении названия. Реальные зоны называются InVideo, OutStream, POP player, POP thumbs, footer_1…4, ntv_1/2, slider — на проде 249 зон остались «без формата», их выручка не попадала ни в одну ячейку, а в списке «Зоны» формы дила этих зон не было. Владелец: зона ADOK и место — одно и то же.

## Решение

Каталог мест = места по умолчанию ∪ все различные названия активных зон AdSpyglass. `matchZonesToPlacements` создаёт отсутствующие места (`slug = placementSlug(name)`, `title = name`, после мест по умолчанию, по алфавиту) и привязывает каждую зону без места: к месту, название которого есть в имени зоны целыми словами (чтобы «Tablink 1» ушёл в место по умолчанию), иначе к месту своего имени. Вызывается после каждой выгрузки зон, ночным `derive` и при старте воркера. Ручная привязка не перетирается. Форматы: `POP…` → POPUNDER, `ntv…` → NATIVE.

## Альтернативы

- **Оставить ручную привязку.** 249 зон руками — не сделают; выручка висит вне сетки.
- **Скрывать пустые колонки.** Пока колонок ~20 и таблица скроллится по горизонтали с закреплённой колонкой сайта; вернёмся, если каталог разрастётся.
