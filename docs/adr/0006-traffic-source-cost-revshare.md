# 0006. Расход — сумма по источникам трафика из ADOK × доля

- Статус: принято
- Дата: 2026-10-02

## Контекст

Расход в спецификации считается по ставкам (`CostRate` × уники из Метрики) или по импорту CSV. Владелец уточнил: в разрезе ADOK по источникам закупки трафика (TubeCrown, Tube traffic, Alex Z и др.) поле, которое ADOK называет «выручкой», на деле — сколько денег заплачено источнику. В ADOK есть `group_by=traffic_source`: 7 источников, с `platforms_ids[]` — по сайту. Отдельного поля стоимости в API нет. Наблюдение на 01.10: сумма этого поля по всем источникам ровно равна выручке сайта (1.000×). Direct — бесплатный трафик.

## Решение

- Ночная джоба по каждому сайту запрашивает `group_by=traffic_source` (+1 запрос на сайт × день) и пишет `FactTrafficSource`: загрузки, показы, клики, выручку.
- Источник сопоставляется с `CostSource` по имени в ADOK (`asgName`); источник с тем же слагом из сида привязывается. Новые источники создаются с `revShare = 1`; Direct, Organic SE и No source — с `0` (это не закупка; уточнение 2026-10-03, после первой реальной выгрузки, где эти источники стояли в расходе на 100%).
- Расход = сумма источника из ADOK × `revShare` → `FactCost` с `origin = ASG`, `rateModel = REVSHARE`, страна `ZZ`. Считается после ночной выгрузки и в `derive`. Импорт CSV по-прежнему перекрывает. Ставки `CostRate` к источникам из ADOK не применяются, чтобы расход не задвоился.
- Долю меняют в «Настройки → Расход», после чего расход пересчитывается за выбранный период — без запросов к API.

## Альтернативы

- **Ставки за 1000 загрузок или кликов** по объёму из ADOK. Не соответствует тому, как оплачиваются источники.
- **Метрика как база расхода.** Не нужна: объём и выручка по источнику уже есть в ADOK.

## Последствия

- Маржа сайта = выручка − сумма платных источников × доля. Раз сумма по всем источникам равна выручке сайта, при доле 100% маржа равна доле Direct и прямых дилов. Если в дашборде это выглядит неправдоподобно — значит, поле всё-таки выручка, и расход надо брать из другого источника (CSV, ставки).
- Разреза «источник × страна» в ADOK нет, поэтому расход источников стоит в стране `ZZ`. Маржа и ROMI верны по сайту, бандлу и сети, но по странам расход источников не виден.
- Пункт чеклиста «ROMI считается там, где есть расход» проверяется по сайт-дням, а не по сайт-странам.
