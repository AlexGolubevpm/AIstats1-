# 0006. Расход — выручка трафика источников из ADOK × доля (ревшара)

- Статус: принято
- Дата: 2026-10-02

## Контекст

Расход в спецификации считается по ставкам (`CostRate` × уники из Метрики) или по импорту CSV. Владелец уточнил: трафик покупается у источников (TubeCrown, Tube traffic, Alex Z и др.) за ревшару, и расход по источнику — это выручка, которую принёс его трафик. В ADOK есть `group_by=traffic_source`: 7 источников, с `platforms_ids[]` — по сайту. Поля стоимости в API нет. Выручка по источникам в сумме ровно равна выручке сайта, а Direct — бесплатный трафик.

## Решение

- Ночная джоба по каждому сайту запрашивает `group_by=traffic_source` (+1 запрос на сайт × день) и пишет `FactTrafficSource`: загрузки, показы, клики, выручку.
- Источник сопоставляется с `CostSource` по имени в ADOK (`asgName`); источник с тем же слагом из сида привязывается. Новые источники создаются с `revShare = 1`, Direct — с `0`.
- Расход = выручка трафика источника × `revShare` → `FactCost` с `origin = ASG`, `rateModel = REVSHARE`, страна `ZZ`. Считается после ночной выгрузки и в `derive`. Импорт CSV по-прежнему перекрывает. Ставки `CostRate` к источникам из ADOK не применяются, чтобы расход не задвоился.
- Долю меняют в «Настройки → Расход», после чего расход пересчитывается за выбранный период — без запросов к API.

## Альтернативы

- **Ставки за 1000 загрузок или кликов** по объёму из ADOK. Не соответствует тому, как оплачиваются источники.
- **Метрика как база расхода.** Не нужна: объём и выручка по источнику уже есть в ADOK.

## Последствия

- Маржа сайта = выручка − выручка трафика платных источников × доля. При доле 100% маржу дают бесплатный трафик (Direct) и прямые дилы.
- Разреза «источник × страна» в ADOK нет, поэтому расход источников стоит в стране `ZZ`. Маржа и ROMI верны по сайту, бандлу и сети, но по странам расход источников не виден.
- Пункт чеклиста «ROMI считается там, где есть расход» проверяется по сайт-дням, а не по сайт-странам.
