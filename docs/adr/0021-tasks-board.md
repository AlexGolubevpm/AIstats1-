# ADR 0021. Задачи: борда команды внутри TubeStat

Статус: принято · 2026-11-03

## Контекст

Владелец хочет вести задачи команды рядом с цифрами, как борду в Notion: колонки Бэклог · Запланировано · В работе · Тест · Готово; в задаче — исполнитель, на что влияем, рекламодатель, формат, сайт; разрез по периодам. Пользователей в TubeStat нет: вход по одному паролю.

## Решение

- **Своя борда, не Notion API.** Задаче нужны ссылки на объекты TubeStat (сайт, формат, рекламодатель, гипотеза) и эффект в $/мес. Синхронизация с внешним сервисом дала бы второй источник правды и ещё один секрет.
- **Исполнитель — имя из списка** (`TeamMember`), а не пользователь. Новое имя в карточке пополняет список; правка — в «Настройки → Команда». Отдельные логины можно добавить позже, не меняя борду.
- **Порядок карточек** — дробная позиция (`position`): карточка, брошенная между двумя, берёт середину, сверху и снизу — шаг 1000. Перестановка не трогает соседей.
- **Перетаскивание** — нативный HTML5 drag-and-drop, без новых библиотек. На телефоне колонки листаются горизонтально, колонка меняется в панели задачи.
- **Периоды** — по датам задачи: задача видна в периоде, если её начало–срок с ним пересекается; без дат — только во «Все».
- **Связь с гипотезами:** «Создать задачу» на странице гипотезы переносит сайт, формат, эффект и «на что влияем» по метрике.
- Каждое изменение — строка `AuditLog` (`entity = Task`); MCP `get_tasks` — только чтение.

## Последствия

- Новые таблицы `Task`, `TeamMember`; данные не затрагиваются. «Удалить демо-данные» чистит и задачи.
- Тесты: unit (периоды, позиция, «на что влияем» по метрике), int (создание, правка с аудитом, перетаскивание, «Готово», фильтры и периоды, задача из гипотезы, команда, MCP), E2E (борда целиком, включая перетаскивание).
