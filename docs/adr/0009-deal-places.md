# 0009. Место на сайте вместо формата в диле; несколько дилов и сетка в ячейке

- Статус: принято
- Дата: 2026-10-06

## Контекст

В форме дила были два поля — «Формат» (`AdFormat`: баннер, попандер…) и «Место на сайте» (одно место, общее для всех сайтов дила). Владелец: для него это одно и то же — дил стоит на конкретных местах (Tablink 1, Underplayer…) конкретных сайтов, причём мест и сайтов может быть несколько, а на одном месте могут стоять несколько дилов (например, по тирам гео). В ячейке «Форматов» нужно видеть эти дилы, ставить их туда и отмечать сетку, которая выкупает место.

## Решение

1. `Deal.placementSlug` заменён таблицей `DealPlace (dealId, siteId, placementSlug)`: любой набор пар сайт × место, несколько дилов на ячейку. В форме — чипы мест под каждым сайтом; отметка места отмечает сайт. Существующие дилы перенесены миграцией (их место — на каждом их сайте).
2. Поле «Формат» из формы убрано. `Deal.format` остаётся в базе и выводится из зон AdSpyglass, привязанных к местам дила: один формат → он; несколько или ни одного → прежнее значение, у нового дила — «Другое». Разрезы по формату (`FactRevenueZone.format`) это не затрагивает — там формат зоны из ADOK.
3. Выручка дила (`FactFixDeal`, по сайту) в ячейках: дил на нескольких местах одного сайта делит факты сайта поровну между ними — других данных о распределении нет.
4. Ячейка: панель с дилами места (убрать с места), привязка существующих дилов (дил, которого не было на сайте, добавляется на сайт), ссылка на новый дил с отмеченным местом, и `SitePlacement.networkId` — сетка, выкупающая место (прямая сетка → own deal, медиация → ротация), как заметка владельца, не факт ADOK.

## Альтернативы

- **Оставить формат как отдельное поле.** Владелец его не заполняет осмысленно и путает с местом; значение, выведенное из зон, точнее.
- **Привязывать дил к зоне, а не к месту.** Зоны ADOK названы произвольно и часто не привязаны к местам; место — то, чем оперирует владелец.
- **Делить выручку дила между местами по показам зон.** Фикс-дил не идёт через зоны ADOK, показов по месту нет.
