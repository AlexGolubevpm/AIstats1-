# 0005. Выручка сеток в разрезах по странам и устройствам — из итога сайта

- Статус: принято
- Дата: 2026-10-02

## Контекст

За 01.10 выручка в дашборде оказалась в 2,58 раза больше, чем в ADOK. Причина — в API, а не в подсчёте: с фильтром `platforms_ids[]` ADOK фильтрует по сайту только свои поля (`hits`, `impressions`, `clicks`, `predicted_income`). Поля стороны сеток (`broker_income`, `broker_hits`) в разрезе по странам по сайту не фильтруются: от 1× до 100× итога сайта. В разрезе по устройствам их почти нет (медиана 0,07×). В разрезе по сеткам и в `group_by=website` они верные. Ингест брал `broker_income` из разреза по странам как есть. Сверка ±2% расхождение увидела, но данные всё равно записала.

## Решение

- Источник истины по выручке и показам сеток для сайта за день — `group_by=website`.
- В разрезах по странам и устройствам выручка и показы сеток сайта раскладываются по ячейкам пропорционально `predicted_income` ячейки. Если его нет — пропорционально показам, если нет и их — загрузкам. Сумма считается методом наибольшего остатка и ровно совпадает с итогом сайта.
- Сверка ±2% сравнивает `predicted_income` разреза по странам с итогом сайта. Так проверяется, что фильтр по сайту сработал.
- Ответ `group_by=website` сохраняется в сырьё и в ночной джобе. `geo:reprocess` пересчитывает старые дни из сырья без запросов к API.

## Альтернативы

- **Брать выручкой `predicted_income`.** Он фильтруется везде, но это прогноз ADOK, а не деньги, которые сообщают сетки. Отказались: выручка в дашборде — `broker_income`, как в итоге сайта.
- **Не писать разрез, если сверка не прошла.** Тогда страны и устройства пропадают почти у всех сайтов: расхождение есть у 15 из 27. Отказались.
- **Запрашивать страны отдельно по каждой сетке.** Ровно это API и не умеет: мульти-`group_by` отвечает 422. К тому же это десятки лишних запросов при лимитах ADOK.

## Последствия

- Итог сайта и сети в дашборде сходится с `group_by=website` до цента.
- Выручка сеток по странам и устройствам — оценка: доля страны в выручке сайта берётся по прогнозу ADOK. На сравнение стран и rev / 1000 loads это влияет мало. Расхождение сеток с прогнозом внутри страны (дискрепанси по выручке) по странам не видно — только по сайту.
- Итог по сети меньше аккаунтного отчёта по сеткам в ADOK примерно на 7%: это выручка, не привязанная ни к одному сайту.
