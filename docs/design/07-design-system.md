# 07. Дизайн-система

Внутренний инструмент на каждый день: **плотность важнее воздуха, цифры важнее декора, цвет несёт смысл, а не украшает**.

**Стек:** Tailwind 4 + shadcn/ui как база примитивов, TanStack Table для таблиц, Recharts для графиков, lucide-react для иконок. Других UI-библиотек не добавляем.

**Где живёт:**

```
src/app/globals.css          токены (CSS-переменные) + @theme для Tailwind
src/components/ui/           примитивы shadcn (Button, Input, Select, Sheet, …)
src/components/data/         доменные компоненты: DataTable, KpiCard, TrendChart, …
src/lib/format.ts            форматирование чисел, денег, процентов, дат
```

## 2. Примитивы (shadcn/ui)

Button (primary / secondary / ghost / destructive; размеры sm / md) · Input · NumberInput (с единицей измерения и парсингом `1 234,56`) · Select · Combobox (поиск, мультивыбор — страны, сайты) · DateRangePicker · Checkbox · Switch · Tabs · Badge · Tooltip · Popover · DropdownMenu · Sheet (боковая панель для форм) · Dialog (только подтверждение деструктивных действий) · Toast · Skeleton · Separator · ScrollArea.

Правила:
- Модалка — только для подтверждения. Формы открываются в Sheet или инлайн.
- Деструктивная кнопка всегда справа и требует подтверждения, если действие нельзя отменить.
- У каждого интерактивного элемента видимый фокус: `outline: 2px solid var(--accent)`.

## 3. Доменные компоненты

### `<DataTable>`

Главный компонент интерфейса. Обёртка над TanStack Table.

```tsx
<DataTable
  columns={[
    { id: "site",    kind: "site",    header: "Сайт" },
    { id: "revenue", kind: "money",   header: "Выручка", share: true },
    { id: "romi",    kind: "percent", header: "ROMI", heat: "vsMean" },
  ]}
  data={rows}
  totalsRow={totals}           // считается на сервере, не суммой строк
  defaultSort={{ id: "revenue", dir: "desc" }}
  density="default"            // default | compact
  pageSize={25}
  onRowClick={(r) => router.push(`/sites/${r.domain}`)}
  expandable={(r) => <NestedNetworks row={r} />}
  exportName="bundle-jav-sites"
/>
```

Колонка описывается **типом значения**, а не рендером. Форматирование, выравнивание и цвет выводятся из типа.

| `kind` | Формат | Выравнивание | Особенности |
| --- | --- | --- | --- |
| `text` | как есть | влево | |
| `mono` | моно 12px | влево | ID, коды |
| `int` | `1 234 567` | вправо | |
| `money` | `$1 234.56` | вправо | `$` в `--text-muted`, на размер меньше |
| `cpm` | `$0.8123` (4 знака) | вправо | |
| `percent` | `12.4%` | вправо | `%` в `--text-muted` |
| `delta` | `+8.3%` / `+2.1 пп` | вправо | Цвет по знаку |
| `share` | полоса-фон + `%` | вправо | Доля рисуется фоном ячейки |
| `country` | флаг + название | влево | Код в тултипе |
| `site` | домен моно + ссылка | влево | |
| `status` | бейдж | влево | Прогноз / выставлено / подтверждено |

Правила: ноль рисуется как `—` в `--text-faint`; заголовок `sticky`; строка «Итого» закреплена снизу с `border-top: 1px solid var(--border-strong)`; сортировка кликом по заголовку; больше 25 строк — пагинация; состояние сортировки и страницы — в URL.

### `<KpiCard>`

```tsx
<KpiCard label="ROMI" value={142.7} format="percent"
         delta={+8.3} deltaMode="pp" spark={series}
         tone="auto" emphasis status="partial" />
```

Значение (Display), подпись (Label), дельта к предыдущему периоду, спарклайн 14 дней. `emphasis` делает карточку шире. `tone="auto"` красит дельту, `neutral` — нет. Отрицательная маржа красит рамку `--negative`. `status="partial"` добавляет значок ⚠ и тултип о неполных данных.

### `<TrendChart>`

`type="line" | "stackedBar" | "area"`. Серии приходят с уже назначенными цветами из базы. Ось Y начинается с нуля (кроме графиков дельты). Сетка горизонтальная, 1px `--border`. Тултип показывает все серии, отсортированные по убыванию. Легенда сверху и кликабельна. Разрыв данных рисуется разрывом линии, а не нулём. Без 3D, градиентов, теней и круговых диаграмм.

### `<PeriodPicker>`

Пресеты «Вчера / 7 дней / 30 дней / Этот месяц / Прошлый месяц» + произвольный диапазон. Пишет `?from=&to=` или `?preset=`. На `/finance` добавляются «Квартал» и выбор месяца.

### `<BreakdownTabs>`

Переключатель разреза: Зоны / Форматы / Сетки / Гео / Девайсы. Значение в `?by=`. Счётчик строк в каждой вкладке.

### `<AlertBadge>`

Уровень (`warning` | `critical`), текст, **обязательная** ссылка на разрез, который породил алерт.

### `<DiscrepancyCell>`

Число и иконка. До ±10% — нейтрально, ±10–25% — `--warning`, дальше — `--negative`. Тултип показывает обе цифры показов.

### `<MoneyStatus>`

Сумма со статусом: прогноз (пунктирная рамка, `--text-faint`), выставлено (иконка документа), подтверждено (иконка галочки). Используется на `/finance`, `/deals` и в фикс-дилах сайта.

### `<EmptyState>`

Три разных варианта:

| Вариант | Текст | Действие |
| --- | --- | --- |
| `no-data` | Нет данных за выбранный период | «Последние 7 дней» |
| `ingest-failed` | Ингест не отработал. Последний успешный: 22.09 14:05 | «Перезапустить» |
| `no-match` | По фильтрам ничего не найдено | «Сбросить фильтры» |

### `<FreshnessIndicator>`

Строка в сайдбаре: источник, время с последнего успешного ингеста, точка (норма / > 2 ч / failed). Ссылка на `/settings/integrations`.

### `<CsvImport>`

Загрузка или вставка CSV → сопоставление колонок → предпросмотр (распознано, не смаплено, итог) → подтверждение. Используется для расхода и фикс-дилов.

### `<AuditLog>`

Лента изменений: кто, когда, поле, было → стало, причина. Используется в карточке дила и в истории импортов.

## 4. Паттерны

- **Формы:** подпись над полем, ошибка под полем, красная рамка и текст. Кнопка «Сохранить» активна, только когда форма валидна и изменена. Черновик длинных форм сохраняется в `localStorage`.
- **Инлайн-редактирование в таблицах:** клик по ячейке → инпут → Enter сохраняет, Esc отменяет. Во время сохранения — спиннер в ячейке, после — короткая подсветка.
- **Уведомления:** Toast внизу справа на 4 секунды; ошибки держатся до закрытия.
- **Подтверждения:** Dialog только для необратимых действий; текст называет объект («Архивировать japan-whores.com?»).
- **Загрузка:** скелетоны по форме контента, не спиннеры.
- **Экспорт:** кнопка «CSV» в заголовке любой таблицы; экспортируется текущий срез с фильтрами.

## 5. Доступность

- Контраст текста не ниже 4.5:1 в обеих темах: проверяется тестом на токенах.
- Всё управляется с клавиатуры: Tab-порядок, Enter/Space, стрелки в таблицах и вкладках.
- Цвет никогда не единственный носитель смысла: у дельт есть знак, у статусов — иконка и текст.
- Графики продублированы таблицей, доступной по кнопке «Как таблица».

## Мобильная раскладка

До `lg` (1024px) сайдбар становится выдвижной панелью: сверху фиксированная полоса высотой 56px с бургером, логотипом и счётчиком алертов; контент начинается под ней (`pt-18`). Панель открывается бургером, закрывается тапом по подложке, крестиком или переходом по ссылке; в ней всегда полные подписи (свёрнутое состояние — только для десктопа). Шапка страницы: действия и выбор периода уходят на всю ширину под заголовок; у выбора периода на телефоне видны только даты. Вкладки разрезов прокручиваются по горизонтали, таблицы — внутри своего контейнера (`-mx-5 overflow-x-auto`), двухколоночные строки форм складываются в одну колонку, боковые панели (`Sheet`) занимают всю ширину. Правило для новых страниц: ничего фиксированной ширины шире 360px без `overflow-x-auto`; проверка — `tests/e2e/mobile.spec.ts` (390×844: ширина окна остаётся 390 на каждой странице и карточке, заголовок не под полосой, меню открывается и закрывается).

**Почему страница «уезжала».** Телефонный браузер, встретив блок шире экрана, расширяет layout-вьюпорт до него и показывает всю страницу уменьшенной. Два источника таких блоков закрыты глобально: `.grid > * { min-width: 0 }` (грид-ячейка не раздувается до min-content таблицы внутри) и правило, что рукописная таблица живёт только внутри `TableScroll` (`components/data/table-scroll.tsx`) с классом `.tbl` (числа не переносятся, таблица прокручивается под краями карточки). `DataTable` на телефоне держит первую колонку прилипшей слева, у прокручиваемых таблиц — тени по краям (`.ts-scroll`), которые видны только там, где есть что прокручивать. Карточки списков (гипотезы, алерты) на телефоне складываются в колонку: текст, под ним эффект и кнопки. KPI: 2 колонки на телефоне, 3 на планшете и десктопе, одна строка только от 1700px; число никогда не переносится, подпись может занять две строки. Легенда графика — своя, над полотном, переносится по строкам и не наезжает на ось.

## Движение

Короткие и мягкие анимации, только на появление и уход: боковая панель `Sheet` въезжает справа (220 мс) и уезжает (160 мс), подложка — fade; поповер периода и диалог подтверждения — лёгкий «pop»; содержимое страницы поднимается на 6px с fade при загрузке (240 мс); тосты — так же. Все через `data-state` Radix и классы `ts-*` в `globals.css`; `prefers-reduced-motion: reduce` отключает всё. Переходы цвета на строках таблиц и кнопках — `transition-colors`.
